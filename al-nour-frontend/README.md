# 🎓 منصة مدرسة النور الخاصة - Al-Nour School Platform

منصة رقمية متكاملة لإدارة المدرسة الخاصة تجمع بين المدير والأساتذة وأولياء الأمور في نظام واحد.

## 🌟 المميزات الرئيسية

### 👨‍💼 لوحة تحكم المدير
- **إحصائيات شاملة**: عدد التلاميذ، نسبة الأداء المالي، نسبة الحضور، التنبيهات
- **إدارة التلاميذ**: إضافة، تعديل، حذف، تصدير Excel
- **إدارة المدفوعات**: متابعة الدفع، تذكيرات تلقائية، رسوم بيانية
- **التقارير والإحصائيات**: متوسط الدرجات، نسبة النجاح، الغيابات
- **التقويم المدرسي**: إدارة الأحداث والامتحانات

### 👨‍🏫 لوحة تحكم الأستاذ
- **جدول اليوم**: عرض الحصص والمواعيد
- **إدارة الدرجات**: إدخال وحساب المعدلات تلقائياً
- **الحضور والغياب**: تسجيل الحضور وإرسال تنبيهات
- **الموارد التعليمية**: رفع الدروس والتمارين
- **المراسلة**: التواصل المباشر مع أولياء الأمور

### 👨‍👩‍👧 لوحة تحكم ولي الأمر
- **متابعة الأداء**: معدل الطفل ونسبة الحضور
- **النتائج والبطائق**: عرض وتحميل البطاقات المدرسية
- **الأداء المالي**: الدفع أونلاين ومتابعة الفواتير
- **المراسلة**: التواصل مع الأساتذة
- **التقويم**: متابعة الأحداث والامتحانات

## 🛠️ التقنيات المستخدمة

### Frontend
- **React 19** - مكتبة بناء واجهات المستخدم
- **Vite** - أداة البناء السريعة
- **Tailwind CSS** - إطار عمل CSS
- **Framer Motion** - مكتبة الحركات والانتقالات
- **React Router DOM** - التنقل بين الصفحات
- **React Hook Form** - إدارة النماذج
- **Yup** - التحقق من البيانات
- **Lucide React** - الأيقونات
- **Recharts** - الرسوم البيانية
- **Axios** - طلبات HTTP
- **React i18next** - دعم اللغات المتعددة

### Backend (قادم)
- **Laravel PHP** - إطار عمل Backend
- **MySQL/PostgreSQL** - قاعدة البيانات
- **JWT** - المصادقة والأمان
- **WebSockets** - الاتصال الفوري

## 📦 التثبيت والتشغيل

### المتطلبات
- Node.js (v18 أو أحدث)
- npm أو yarn

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
git clone <repository-url>
cd al-nour-frontend
```

2. **تثبيت المكتبات**
```bash
npm install
```

3. **تشغيل المشروع**
```bash
npm run dev
```

4. **فتح المتصفح**
```
http://localhost:5173
```
